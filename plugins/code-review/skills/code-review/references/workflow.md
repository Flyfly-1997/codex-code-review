- **输入来源与后续编辑。** 比对实际支持的输入方式，例如表单、导入和 API。对同一内容比较首次写入、替换与人工编辑。核对内容来源、最后写入者与版本条件，以及拒绝时反馈的原因。
- **确认、取消与时间边界。** 核对确认、取消、重复和不合法输入。比较截止前创建、截止后确认的状态和提示，并查清取消信号在哪个阶段生效。
- **异常兜底与语言。** 从缺失、失效、重试或恢复入口走到用户最终看到的状态和文案，核对正常答复与兜底是否沿用同一语言和原因。
- **提交、回执与恢复。** 分开检查业务写入、回执保留、事务提交后的通知或索引。模拟推理两个时间点，提交后进程中断，以及恢复前关联记录被撤销或删除。先确认实际删除分支和已有补偿，区分有记录但未补做与记录被删除。
- **高频入口与外部调用。** 从普通、无待处理状态的请求起计，再看确有待处理状态的分支。标注权限、功能开关和短路顺序，分别计算查询、循环及外部判断调用。存在锁时核对哪些操作在持锁期间发生。
- **文本匹配与编辑边界。** 从编辑器或客户端真实产生的数据开始，核对重复词前缀、无空格语言、局部更正和多来源组合。按候选选择、游标推进、最终校验顺序追踪。多来源需要证明入口确实产生所报的片段顺序。
- **异步失败与最终状态。** 比较服务拒绝、依赖异常、超时和重试。逐步查原因如何跨层传递、还有哪些普通输出会被中断、消费者是否收到最终事件。
- **生命周期与一次性约束。** 对照主对象和关联标记的创建、续期、硬截止、释放和重试；标出作用域和仍有效的上层限制。
